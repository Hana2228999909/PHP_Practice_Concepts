# PHP Assignment 2

## Course
PHP & MySQL

## Activity
Chapter 3 Assignment - Arrays

## Description

This assignment contains three PHP programs that demonstrate
the use of one-dimensional arrays and two-dimensional associative arrays.

## Question 1 - One Dimensional Array

The program declares an array with the following values:

5, -7, 12, 10, -7, 11, -6, 12, 1, -7, 2, 9

The program performs the following tasks:

- Prints all elements of the array.
- Calculates the total of all elements.
- Calculates the total of even elements.
- Calculates the total of odd elements.
- Finds the minimum element and its positions.
- Finds the maximum element and its positions.

## Question 2 - Two Dimensional Associative Array

The program creates a two-dimensional associative array.

### Rows

- Light
- Normal
- Dark

### Columns

- Red
- Green
- Blue

The program then prints the array elements in a table.

## Question 3 - Student Information

The program creates a two-dimensional associative array containing
student information.

### Columns

- Name
- Phone
- Address

The program prints the student information in a table.

   assignment2.php
